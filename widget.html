Embed the Senedd 2026 Constituency Lookup Widget

Use the code below to embed the postcode lookup on your website. It works best in sidebars, articles, and election explainers.

Live preview

This is what your embedded widget will look like.

If you need a different default height, you can change the height value below.

Option A: Simple iframe embed (recommended)

Works on WordPress, Squarespace, Wix, custom CMSs, and most newsroom platforms. 

<iframe
  src="https://senedd2026.co.uk/widget.html"
  style="border:0;width:100%;max-width:460px;height:320px;"
  loading="lazy"
  title="Senedd 2026 constituency lookup"></iframe>

Tip: set max-width to fit your page column (for example 380–520px).

Option B: Script embed (auto-sizing)

Use this if your CMS allows scripts. It will size itself to the widget content. 

<div id="senedd2026-widget"></div>
<script src="https://senedd2026.co.uk/embed.js"></script>
<script>
  SeneddLookup.attach('#senedd2026-widget');
</script>

If your platform blocks scripts, use the iframe option above.

Notes for publishers

  • Lookup supports Welsh postcodes only.
  • Postcode is used only to complete the search and is not stored.
  • Location lookup uses the browser’s geolocation prompt.
  • Data source: Senedd Cymru/Welsh Parliament boundary data.
